1. Latar Belakang & Tujuan

Bagian ini menguraikan alasan mendasar mengapa proyek KostAds diinisiasi. Dalam industri properti kost, persaingan mendapatkan penyewa sangat ketat. Kecepatan *loading website* dan kemudahan *tracking* konversi Google Ads menjadi kunci efisiensi anggaran pemasaran. Interaksi di bawah ini merangkum empat pilar tujuan utama dari ekosistem digital ini.

⚡

High-Speed Landing Page

Menyediakan halaman penawaran berkecepatan tinggi yang disukai algoritma Google Ads untuk meningkatkan *Quality Score* iklan.

💻

Manajemen Konten Mandiri

Memberikan kontrol penuh kepada pemilik kost untuk mengelola harga, fasilitas, dan foto properti secara mudah melalui CMS.

🔗

Integrasi Tag Instan

Memasang Tracking ID Google Ads (AW-XXX) langsung dari Dashboard tanpa perlu menyentuh kode pemrograman sama sekali.

📈

Pelacakan Konversi WA

Melacak setiap klik tombol WhatsApp secara akurat untuk mengukur efektivitas dan Cost per Lead dari kampanye iklan.

2. Ruang Lingkup Proyek (Bundle B)

Proyek ini mengadopsi skema "Bundle B: Full Management". Berbeda dengan paket standar, paket ini memberikan fleksibilitas pengelolaan di sisi Back-end sekaligus performa tinggi di sisi Front-end. Silakan navigasikan tab di bawah ini untuk melihat rincian fitur pada masing-masing modul aplikasi.

Fitur Pengelola Ekosistem

  • ✓

    Autentikasi Aman

    Sistem login yang aman dan rahasia khusus pengelola.

  • ✓

    Google Ads Tag Manager

    Form input `Google Tag ID` dan `Conversion Label` yang tersisip dinamis ke Landing Page.

  • ✓

    Dynamic Pricing CMS

    Ubah harga sewa (per bulan/tahun) secara instan tanpa perlu coding.

  • ✓

    Gallery Manager & Smart Feedback

    Sistem CRUD foto kamar dengan notifikasi pop-up SweetAlert2 di tengah layar.

Fitur Sisi Penyewa (Front-End)

  • ✓

    High-Performance UI

    Desain antarmuka modern yang 100% responsif di smartphone dan desktop.

  • ✓

    Dynamic Content Synchronization

    Menampilkan harga dan galeri foto terbaru yang langsung ditarik dari database Admin.

  • ✓

    Direct WhatsApp Conversion

    Tombol CTA WhatsApp yang sudah terintegrasi secara teknis dengan *trigger event* Google Ads.

  • ✓

    SEO Dasar & Image Optimization

    Optimasi gambar otomatis untuk mencegah website lambat dan mendukung pencarian organik.

4. Arsitektur Teknologi

Membangun ekosistem yang berkinerja tinggi membutuhkan fondasi teknologi modern. Berdasarkan proposal standar, kami menetapkan arsitektur *Decoupled* yang memisahkan sisi tampilan (*Front-end*) dan sisi logika (*Back-end*) untuk mencapai skor Google PageSpeed tertinggi.

Next.js
FRONT-END

SSG (Static Site Generation) untuk *loading* Landing Page instan.

Tailwind
STYLING UI

Framework CSS untuk membangun komponen yang 100% responsif.

Express.js
BACK-END API

Menangani logika bisnis, *routing* CMS, dan *security authentication*.

NoSQL / SQL
DATABASE

Penyimpanan data harga, foto, dan konfigurasi yang terenkripsi.
